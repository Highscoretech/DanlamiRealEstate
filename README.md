# danlamirealestate.com

Next.js site for Dan Lami Real Estate — luxury property sales, investment advisory and
development in Lagos.

```bash
npm install
npm run dev      # http://localhost:3000
```

## Where things live

| Path | What |
|---|---|
| `app/` | Routes. One folder per page, App Router. |
| `components/site/` | Header, Footer, Cta band, PageHero, PhotoSlot, LeadForm. |
| `content/site.ts` | Company facts, navigation, contact details, social links. |
| `content/properties.ts` | Property listings and Signature Developments. |
| `content/areas.ts` | Location landing pages — Lekki and the three estates. |
| `content/guides.ts` | Long-form buyer guides. |
| `lib/sheets.ts` | Google Sheets append, via a service account. No SDK. |
| `lib/seo.ts` | `pageMetadata()` — every page's title, description and canonical. |
| `lib/schema.ts` | JSON-LD builders. |
| `docs/` | Client copy, brand notes, SEO strategy, open questions. Read these first. |
| `assets/` | Original client material, organised. Not served. |
| `public/` | Served files — logo, portrait, property photos. |

## Content

All the site copy comes from the client's own 18-section document, transcribed verbatim in
[`docs/client-content.md`](docs/client-content.md). If you are changing wording, check there
first — most of it is theirs, not ours.

**No statistics appear anywhere on the site.** The client explicitly asked that unverified
numbers — clients served, transactions, agents trained, years of experience — stay off until
they confirm them. Do not add a stats band without checking.

## Design

Light editorial. The palette is built from the only colour the brand owns: the teal gradient
inside the logo mark, measured at `#0D90BE → #0A4354`. Neutrals are biased slightly toward
that teal rather than left as flat grey. Full notes in [`docs/brand.md`](docs/brand.md).

Type is Fraunces for headings and Manrope for everything else, both loaded through
`next/font`. Single theme by choice — this is a brand site, so it commits to one look.

Design tokens are all in `app/globals.css`. There is no CSS framework.

## SEO

Strategy, what is built and what the client still has to do:
[`docs/seo.md`](docs/seo.md). The short version — we cannot beat PropertyPro and
Nigeria Property Centre on listing volume, so the site targets the long tail
(named estates, specific configurations) and the questions the portals do not
answer.

Two rules when adding a page:

1. Metadata goes through `pageMetadata()` in `lib/seo.ts`. That is what sets the
   canonical, so nothing may bypass it.
2. Add the route to `app/sitemap.ts`.

## Forms

`/contact` and `/partners` both post to `app/api/leads/route.ts`, which appends a row to a
Google Sheet — `Enquiries` and `Partners` tabs of the same spreadsheet.

Until the client provides their Google account, the forms still work: submissions are logged
server-side and the visitor gets a normal confirmation, so nothing breaks in the meantime.
Setup instructions are in [`.env.example`](.env.example).

The partner form is deliberately short. It does not ask for ID documents or bank details —
those are collected off the site after a conversation, which keeps sensitive personal data
out of scope.

## Photography

There is none yet. Everything the client has sent so far is Instagram screenshots at around
500px wide, which is unusable at any real size.

`PhotoSlot` renders a designed stand-in panel wherever a photo is missing. To swap in a real
photo: drop the file in `public/properties/` and set `image` on that property in
`content/properties.ts`. The component handles the rest.

## Before this can launch

See [`docs/open-questions.md`](docs/open-questions.md). The blocking items:

- Vector or transparent-PNG logo from the client's designer. The PNGs in `public/brand/` were
  generated by knocking the white background out of their JPEGs — good enough to build
  against, not good enough to ship.
- Real property photographs.
- A decision on **Danlami** vs **Dan Lami** — the logo and the copy document disagree.
- A decision on `.com` vs `.ng` — their flyers advertise a different domain from the one we hold.
- RC number and registered address, before the footer can claim "Ltd".
- Privacy policy and terms, since the forms collect personal data.

## Deploying

```bash
npx vercel
```

Set the three environment variables from `.env.example` in the Vercel project settings before
the forms will write to the sheet.
